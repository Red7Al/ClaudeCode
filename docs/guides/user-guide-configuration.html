User Guide

Configuration

Your personal preferences and platform settings

The Configuration tab is where you tune the platform to your own preferences. Some settings are personal to you; shared settings that affect everyone can only be changed by an admin (and appear read-only otherwise).

01

Preferences

  • Scanner Report filter defaults — the Quality, reward-to-risk and RVOL floors applied to your Scanner view and to your daily scanner-report email. Set these once and every list you see respects them.
  • Replay / performance settings — the model wallet, maximum position size (default 5%) and maximum open positions (default 50) used by the Performance replays.
  • Automated stop-loss amendment — an optional trailing-stop threshold (a percentage; 0 means off). When set, the platform can tighten the stop on a live IG position as it moves in your favour.
02

Credentials

Your IG connection lives here (see the "Adding IG credentials" guide). Admins also manage the shared service credentials — such as the Slack and email tokens — from this section; these are stored encrypted and never displayed in full.

03

Execution sources

This controls where staged orders are routed and which sources the platform draws on when preparing them. Most users never need to change it.

04

Tab Visibility

Admins can show or hide individual tabs for the platform here. See the "Feature — Tab Visibility" guide for how it behaves.

Personal settings take effect immediately for you. Shared settings change the platform for everyone, so they are gated to admins and logged.
