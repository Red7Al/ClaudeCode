Support — Configuration tabs

The user and admin configuration surfaces

Configuration comes in two forms. Configuration (User) holds settings personal to each signed-in user; Configuration (Admin) holds shared settings that affect the whole platform. Markets (User) and Markets (Admin) follow the same split.

01

Configuration (User)

  • Preferences — Scanner Report filter floors (Quality, R:R, RVOL), replay wallet and position sizing, and the optional automated stop-loss amendment threshold.
  • Credentials — the user's own IG connection.
02

Configuration (Admin)

  • Shared credentials — the platform's service tokens (Slack, email, scheduler) held in the encrypted store and editable only by admins.
  • Execution sources — where orders route and which sources feed order preparation.
  • Tab Visibility — show/hide tabs platform-wide.
  • Engine / trading settings — the shared parameters that govern the scan and the trading logic.
03

How access is enforced

The split is enforced on the server, not just hidden in the interface. A shared (app-scope) setting is only writable by an admin; a user-scope setting is writable by its owner. IG credentials are owner-scoped; the shared service credentials are admin-only.

When a support engineer says a setting looks read-only, that is usually correct behaviour — shared settings are admin-write. Confirm the role before treating it as a bug.
