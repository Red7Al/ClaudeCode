Feature — Tab Visibility

Showing and hiding tabs across the platform

Tab Visibility lets an admin control which tabs appear, keeping the navigation focused on what is actually in use. It is found in the Configuration area.

01

How it works

  • Each tab has an on/off switch, grouped by area (for example the instrument tools are grouped together).
  • Turning a tab off hides its button for everyone it would otherwise apply to — including admin tabs.
  • A few tabs are hidden by default and only appear once switched on (for example Multi-Factor Momentum). Most tabs, including Documentation and Instruments, are visible by default.
02

What visibility does not override

Visibility is layered on top of your role, not instead of it. Hiding a tab cannot grant access a role does not have, and role restrictions still apply even if a tab is switched on:

  • Admin-only tabs never appear for non-admins, whatever the visibility switch says.
  • The Support role always sees only its three read-only operations tabs.
  • Admins always retain access to User Management so they can never lock themselves out.
If a colleague reports a missing tab, check three things in order: are they logged in, does their role include that tab, and is the tab switched on in Tab Visibility?
