Support — Posting reports to X

Publishing setup cards to the public X account

The platform publishes a curated, public-facing selection of the best setups to X (Twitter). The X Posts tab is where these publications are reviewed and managed.

01

What gets published

Only the strongest setups qualify. Two filters keep the public feed trustworthy: no chasing (a setup whose price has already run too far past the entry is dropped), and a quality floor (only genuinely clean, high-scoring patterns are published; weaker ones stay internal). Slack receives the fuller internal list first; X receives only the top few.

02

The X Posts tab

  • Lists what has been published, with the card image and its status.
  • Each card is rendered server-side from the setup's data — the same numbers shown across the platform.
  • Sortable and searchable like the other tables.
03

Credentials and cost

Posting needs the X API credentials in the shared credential store (Configuration (Admin)). Publishing to X draws on the funded X API allowance — see the "Operations — Funding X publications" guide for how that is topped up and monitored.

Publishing to X is a public action. Only the vetted, quality-gated selection should ever reach the public feed; the internal watch-list stays on Slack.
