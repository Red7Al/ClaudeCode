Operations — Funding X publications

Keeping the X API allowance topped up

Publishing setup cards to X consumes the X API allowance on the platform's X developer account. This guide covers keeping that funded so publications do not stall.

01

Why funding matters

  • The X API is paid per tier; posting draws against the account's monthly allowance.
  • If the allowance is exhausted or the billing lapses, publication attempts fail and the public feed goes quiet even though the internal Slack list keeps flowing.
02

Monitoring

  • Watch the X Posts tab for a run of failed publications — the usual first sign of an allowance or billing problem.
  • Batch Activity records each publication run's outcome; repeated failures there point the same way.
  • System Logs will carry the underlying API error (rate limit, auth, payment).
03

Topping up

Funding and tier changes are made in the X developer / billing portal for the platform's X account, using the account owner's payment method. Update the API credentials in Configuration (Admin) only if the keys themselves change; a top-up alone does not change the keys.

A payment or billing action on the X account is made by the account holder in X's own portal — it is not performed from this platform.
