Operations — Batch Activity

The record of automated batch runs

Batch Activity is the audit trail of the platform's batch processes — the report runs, publication runs, email sends and similar background work. It is available to Admin and Support.

01

What it records

  • Each batch run, with when it ran and how it finished.
  • A summary of what the run did (for example, how many recipients a scanner-report email reached, or how many cards were published).
  • Failures, so a run that did not complete is visible rather than silent.
02

How it relates to the other operations tabs

  • System Logs shows the low-level server log; Batch Activity shows the higher-level outcome of each scheduled job.
  • Scheduled Jobs shows the schedule and GitHub run stats; Batch Activity shows what the run actually did on this platform.
When a scheduled job reports success on GitHub but users report a missing outcome (no email, no post), Batch Activity is where you confirm whether this platform recorded the run and what it did.
