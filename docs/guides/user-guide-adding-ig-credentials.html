User Guide

Adding IG credentials

Connecting your IG account so the platform can read positions and place orders

To see your IG positions and place orders from the platform, you give it your own IG login and an IG API key. They are stored encrypted, used only for your own account, and never shown back in full once saved. This guide shows where to get the API key and where to enter everything.

01

What you need

  • Your IG username and password — the ones you log in to ig.com with.
  • An IG API key (steps below).
  • Your IG account ID — the short reference IG shows for the account you trade with (My IG, under your accounts).
The platform connects to IG's LIVE service only. A demo account, or an API key made for the demo environment, will not work.
02

Getting an API key from IG

  1. Log in to your account at ig.com.
  2. Open My IG, then Settings, and find the API keys section.
  3. Generate a new API key and give it a name you will recognise.
  4. Copy the key straight away — you paste it into the platform once.
03

Entering the credentials

  1. Sign in to the web application and press the green ⚙️ Settings button at the right-hand end of the tabs. It opens Configuration.
  2. Press 🔑 IG Credentials.
  1. Fill in all four boxes — IG API key, IG username, IG password and IG account ID — then press Save IG credentials.

Once saved, each field shows SET and only its last four characters. To change one later, type the new value in its box and save again; boxes you leave empty keep their current value.

04

If you have not added them yet

The IG pages show this banner until your credentials are saved. Open IG settings takes you straight to the IG Credentials panel.

Once saved, open the IG Account tab — your positions and balance should load.

Never send your API key or password by email or chat. If you think a key has been exposed, delete it in My IG, generate a new one, and save the new key here.
