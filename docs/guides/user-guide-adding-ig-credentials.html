User Guide

Adding IG credentials

Connecting your IG account so the platform can read positions and stage orders

To see your live IG positions and stage orders from the platform, you supply your own IG API credentials. The platform stores them in its encrypted credential store — they are never shown back in full once saved. This guide shows how to obtain the API key and where to enter it.

01

What you need

  • Your IG username and password.
  • An IG API key (obtained from IG, steps below).
  • Whether you are connecting a demo or a live account — they use different endpoints.
02

Getting an API key from IG

  1. Log in to your account at ig.com.
  2. Open My IG, then the settings area, and find the API keys / developer section.
  3. Generate a new API key. Give it a recognisable name.
  4. Copy the key immediately and keep it somewhere safe — you will paste it into the platform once.
A demo API key only works against the demo environment, and a live key only against the live one. If positions do not load after saving, the most common cause is a demo key pointed at live (or vice-versa).
03

Entering the credentials

  1. Sign in to the web application and open Configuration.
  2. Go to the Credentials section.
  3. Enter your IG username, password and API key in the IG fields, and select demo or live.
  4. Save. The fields will show as set (masked) rather than echoing the value back.

Once saved, open the IG Account tab — your live positions and balance should load, and the Fees tab will begin reconciling against IG's own records.

For security, never share your API key by email or chat. If you believe a key is compromised, revoke it in My IG and generate a new one, then update it in Configuration.
